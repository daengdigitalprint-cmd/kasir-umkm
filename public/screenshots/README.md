# PWA Screenshots

Folder ini berisi screenshot untuk PWA yang akan ditampilkan di app store atau saat install prompt.

## Ukuran yang Dibutuhkan

### Desktop Screenshots
- **desktop-1.png**: 1280x720 - Dashboard utama aplikasi kasir
- **desktop-2.png**: 1280x720 - Halaman POS
- **desktop-3.png**: 1280x720 - Halaman produk

### Mobile Screenshots  
- **mobile-1.png**: 390x844 - Tampilan mobile aplikasi kasir
- **mobile-2.png**: 390x844 - POS mobile
- **mobile-3.png**: 390x844 - Produk mobile

## Cara Menambahkan Screenshots

1. Ambil screenshot dari aplikasi yang berjalan
2. Resize sesuai ukuran yang dibutuhkan
3. Simpan dengan nama yang sesuai
4. Update manifest.json jika diperlukan

## Tools untuk Screenshot

- **Desktop**: Browser DevTools → Device toolbar
- **Mobile**: Browser DevTools → Responsive design mode
- **Real Device**: Screenshot langsung dari device

## Format yang Disarankan

- **Format**: PNG atau JPEG
- **Quality**: High quality untuk app store
- **Compression**: Optimize untuk web
- **Naming**: Descriptive names untuk easy identification
